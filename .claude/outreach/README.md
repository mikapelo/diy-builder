## Principes copywriting respectés

| Principe | Application |
|---|---|
| **Subject précis** | Pas « Partenariat » générique, mais une promesse concrète |
| **Ouverture spécifique** | Référence à quelque chose qu'ils ont fait/publié (pas template froid) |
| **Body < 150 mots** | Court, scannable mobile, 1 paragraphe = 1 idée |
| **1 chiffre + 1 promesse + 1 question** | Trio efficacité cold email |
| **CTA conversation** | Demande d'appel ou de réponse, pas de signature directe |
| **Aucun anglicisme** | « démarche » pas « process », « retour » pas « feedback » |
| **Signature humaine** | Mikael + prénom, pas « L'équipe » |
